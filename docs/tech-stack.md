## Frontend (`frontend/`)

### Stack

| Concern | Choice |
|---|---|
| Build tool | Vite |
| UI | React (single-page app) |
| Language | TypeScript |
| Styling | Tailwind CSS v4 (`@tailwindcss/vite`) |
| Components | shadcn/ui (Radix base, Nova preset, Lucide icons) |
| API access | Relative `/api/*` calls; Vite dev proxy to the backend |
| Linting | `oxlint` |

### Versions

| Package | Version |
|---|---|
| `vite`, `@vitejs/plugin-react` | 8, 6 |
| `react`, `react-dom` | 19 |
| `typescript` | 6 |
| `tailwindcss`, `@tailwindcss/vite` | 4.3 |
| `shadcn` | 4.21 |
| `radix-ui` | 1.6 |
| `lucide-react` | 1 |
| `class-variance-authority`, `cn` | 0.7, 0.4 |

### Conventions

- No inline Tailwind utilities in app JSX. Define semantic classes with `@apply` in `src/styles/components/*.css` and use those names.
  - `src/styles/globals.css` — single entry: Tailwind, shadcn theme, component style imports
  - `src/styles/components/*.css` — one file per UI area
- `src/components/ui/` is generated by shadcn (`npx shadcn add <name>`); treat as vendor code, don't hand-edit, excluded from lint. Style it from app code by passing semantic class names.
- Import alias `@/` → `src/`.
- Only `VITE_*` env vars are bundled into the browser; never put secrets in them.

### Excluded

Next.js / SSR, state-management libraries, other UI component libraries, inline Tailwind utilities in app JSX.

## Backend (`backend/`)

### Stack

| Concern | Choice |
|---|---|
| Framework | NestJS (ESM) |
| Language | TypeScript |
| Database | Neon Postgres |
| ORM / migrations | Prisma |
| Validation | zod (env + request bodies) |
| Scheduling | `@nestjs/schedule` for the worker poll loop |
| GitHub | GitHub App — built-in `fetch` + `crypto` for JWT |
| Notifications | Slack Incoming Webhook |
| AI | Groq or Gemini free tier via `fetch` |
| Local webhooks | [smee.io](https://smee.io) channel to localhost |
| Linting / format | `oxlint`, `prettier` |

### Versions

| Package | Version |
|---|---|
| `@nestjs/*` | 12 |
| `typescript` | 6 |
| `zod` | 4 |
| `prisma`, `@prisma/client` | 7.10.0 (pinned stable; npm `latest` is an 8.0 RC) |
| `oxlint`, `prettier` | 1, 3 |

### Conventions

- Env loaded with Node's built-in `process.loadEnvFile()`; validated once at boot, fails fast listing names only.
- Logging: Nest `ConsoleLogger` subclass; JSON in production, secrets redacted.
- Global route prefix `/api`.

### Excluded

Automated tests (Jest / Vitest), Redis/BullMQ, Docker, websockets, Octokit, `dotenv`.
